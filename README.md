# Campusly

A responsive, browser-based college event discovery and management website. Browse campus events, search and filter by category, use the monthly event calendar, discover clubs, join groups, save events, RSVP, and add events to the lineup. Event listings, club memberships, saved events, and RSVPs persist in the browser's local storage.

## Run it

Open `index.html` in a modern browser. No build step, package installation, or server is required.

Event photography and fonts are loaded from Unsplash and Google Fonts; an internet connection is needed for those assets. The site remains usable without them.
